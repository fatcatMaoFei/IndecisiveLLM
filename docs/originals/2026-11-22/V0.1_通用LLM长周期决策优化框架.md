> **核心命题**　让 LLM 负责理解、生成候选行动与语言表达；让一个可检查的概率决策层负责高维隐藏状态推断、信息获取、策略选择和长期收益评价。目标不是让某句话更有说服力，而是让整个交互轨迹的期望效用更高。
>
> **文档性质**　本文件是研究框架和可证伪假设的原始记录，不是已经通过实验验证的系统。销售、招聘、科研合作、助理执行等都只是应用环境，不限定模型的适用领域。

# 1. 研究问题与原始动机

**研究问题。** 在信息不完全、多主体交互且目标延迟兑现的环境中，能否在现有语言模型之上增加一层**显式、可校准、可规划的长期决策机制**，使其长期累积收益高于只根据对话历史直接生成下一条回复的 LLM？

最初的直觉来自人际合作与 RA 招聘：对方可能重视执行速度、科研质量、未来合作成本、经费、其他候选人等不同因素。行动者不知道这些因素的真实数值，但可以从对方主动邀约、提出任务、回复方式等信号形成概率判断。行动不只是“回答”，还可能是快速交付、补充证据、询问关键信息、保持等待或改变沟通时机。高质量交付本身也是一种**可核验的能力信号**，可能改变对方的判断。

这是一种通用结构，而不只是招聘心理学：**需求推断 → 隐藏状态建模 → 信号观测 → 策略选择 → 环境和他人信念变化 → 收益反馈 → 模型更新。**

## 1.1 核心研究假设（待验证）

- **H1｜信念价值：**显式、校准的隐藏状态后验优于直接让 LLM 在长上下文中隐式猜测。
- **H2｜规划价值：**在同一 LLM、同一工具、同一交互预算下，长期决策规划优于只看下一步得分的策略。
- **H3｜信息价值：**允许主动询问或观察的策略，在信息成本可控时优于始终立即行动。
- **H4｜信号与多主体价值：**建模“对方如何看待我们的行动”能在某些战略交互中提高决策质量。
- **H5｜跨场景迁移：**共享的信念—决策接口在多个环境中均能产生可测增量，而不是依赖某一个销售或谈判基准。
- **H6｜可审计性：**记录每一步信念、预测、候选行动及实际结果，可以区分“改变话术”和“改善长期收益”。

# 2. 通用数学定义

将每个问题环境表示为多主体、部分可观测的序贯决策过程。时间步 $t=0,1,\ldots,T$，各场景有不同的观测、动作和奖励定义，但共用一个决策接口。

| 符号 | 含义 | 实际例子 |
|:---|:---|:---|
| $x_t$ | 环境可见状态 | 任务进度、历史对话、已发生的交付 |
| $\theta_t$ | **高维隐藏状态** | 需求、偏好、预算、竞争者、权限、隐性约束 |
| $h_t$ | 截止 $t$ 的可用历史 | 观察、回复、行动及已兑现结果 |
| $b_t(\theta)$ | 对隐藏状态的后验信念 | 某项需求或约束为真的概率分布 |
| $a_t$ | 可执行的**策略性行动** | 提问、承诺、交付、等待、选择方案或回复 |
| $o_{t+1}$ | 行动后的新观测 | 对方答复、资源状态变化、实验结果 |
| $r_t$ | 即时效用及成本 | 任务推进、信任变化、时间与资源开销 |
| $\pi$ | 从信念到策略动作的政策 | 先收集信息还是立刻交付 |
| $\gamma$ | 长期折现因子 | 对长期目标相对即时收益的重视程度 |

**一次性选择的贝叶斯决策问题：**

$$
a^*=\arg\max_{a\in\mathcal A}\;\mathbb E_{\theta\sim p(\theta\mid E)}[U(a,\theta)] .
$$

这保留了最初设想：根据观察证据 $E$ 推断未知需求和决策框架，再选择期望收益最大的交付或沟通方式。当收益或行动带有随机性时，$U$ 还应对后续响应与外部变化取期望。

**长期目标：**

$$
\pi^*=\arg\max_{\pi}\;\mathbb E_{\pi}\!\left[\sum_{t=0}^{T}\gamma^t\,r(x_t,\theta_t,a_t,o_{t+1})\right]
$$

可同时加入执行成本、关系质量、信誉、可信度、风险、合规性及其他场景目标。更通用的做法是令 $r_t=\mathbf w^\top\mathbf r_t-c_t$，其中权重 $\mathbf w$ 随任务和用户授权而定；对不可交易的底线使用**硬约束**，而不是用高收益将其抵消。

## 2.1 贝叶斯隐藏状态更新

收到新观察后，不是把对方固定成某个人设，而是更新完整的概率分布：

$$
b_{t+1}(\theta')\propto p(o_{t+1}\mid\theta',a_t,h_t)\int p(\theta'\mid\theta,a_t,x_t)\,b_t(\theta)\,d\theta .
$$

第一部分是观察的**似然**，第二部分是隐藏状态**随时间和行动的转移**。例如，对方今天的预算、紧迫性或信任程度可能因外部事件和我们交付的成果而变化；不能把它们全当静态参数。

信号也可能是战略性的：同一句“之后再谈”，在对方确实没经费、正在比较候选人、或礼貌婉拒时产生的概率不一样。更新时应比较多个竞争解释，不凭单个措辞直接下结论。

# 3. 高维隐藏状态：完整角色与决策框架

我们不预设只有三个性格标签。隐藏状态是**多层、多主体、可扩展的联合变量系统**。高维允许表达丰富现实；实际估计时应采用层级结构、稀疏依赖、先验与可辨识性检验，避免每个场景都需要海量样本。

| 模块 | 典型隐藏变量 | 可用观测或证据 |
|:---|:---|:---|
| 目标与需求 | 近期目标、长期目标、排序权重、不可牺牲条件 | 任务描述、已选择的方案、反复强调的标准 |
| 资源与约束 | 经费、时间、人力、制度门槛、审批权限、排期 | 官方流程、行动窗口、明确的限制陈述 |
| 选择空间 | 其他候选、替代方案、退出选择、机会成本 | 公开招聘、竞争强度、对比性问题 |
| 决策框架 | 风险偏好、损失厌恶、证据要求、否决规则 | 以往决策、对风险与失败的反应 |
| 信念与认知 | 对我们能力的判断、对外部世界的主观判断 | 追问、赞许、质疑、是否给予信任 |
| 高阶信念 | 对方认为我们如何理解他；其他主体如何评价双方 | 多轮互动和第三方可公开信号 |
| 时间与阶段 | 紧迫性、截止日、决策阶段、关系成熟度 | 回复节奏、任务安排、是否主动推进 |
| 社会与组织 | 影响者、负责人、决策链、社会规范 | 组织结构、会议参与者、信息转发 |
| 关系与信誉 | 信任、可靠性评价、过去承诺兑现情况 | 历次交付、后续合作意愿 |
| 情境与外因 | 市场变化、政策、突发事件、可选资源变化 | 可验证的外部事件和系统状态 |
| 感知与观测 | 信号噪声、选择性披露、沟通渠道、误解概率 | 邮件、口头消息、平台行为和延迟 |
| 自身状态 | 能力、时间预算、可承诺范围、目标、成本 | 自身资源、任务日志、实际交付 |
| 多主体耦合 | 竞争者行动、联盟、互相影响、共同资源 | 公开事件、合作网络、可获准的记录 |

**关键建模原则：**保留联合依赖，而不是把所有变量独立相乘。例如“紧迫性”和“预算”可能通过“审批周期”关联；“竞争者数量”和“招聘概率”不一定线性相关。可用动态概率图、分层贝叶斯模型、粒子信念或结构化近似后验来处理。

隐藏状态需分为：已确认事实、可验证但未确认、统计推断、无法识别。**增加变量数量不自动产生准确性**；准确性由可检验的预测质量、校准性及跨环境稳定性决定。这不会削弱框架的高维定位，反而使高维框架成为科学模型。

# 4. 信号博弈：行动也在改变对方的信念

传统“理解对方”只是在推断；信号博弈进一步承认：**我们的行动会作为证据，被对方用来推断我们的类型和能力**。行动者与对方互相更新认知，这可以改变后续选择。

设 $q$ 为观察者对某一能力的先验概率，$s$ 为可核验交付信号，$L_H=p(s\mid H)$ 和 $L_L=p(s\mid\neg H)$ 是两种能力类型下发出信号的似然，则：

$$
p(H\mid s)=\frac{L_Hq}{L_Hq+L_L(1-q)} .
$$

当 $L_H/L_L$ 大于 1 时，信号使高能力假设的后验上升。交付速度、结果质量、复现记录、长期一致性等可以组成信号，但其区分力必须通过观察数据估计，不能单凭我们认为“震撼”就设定一个很大的似然比。

进一步引入**有限层级的心智模型**：我们持有对方偏好的信念；对方也持有关于我们的信念；在必要时加入对方如何理解我们意图的第二阶信念。递归层数应可控，并通过消融判定额外复杂度是否值得。

**跨情境意义。** 面试中快速高质量交付是能力信号；科研合作中公开实验与负结果是可靠性信号；客户服务中兑现承诺是信任信号；协作 Agent 中可检验的行动轨迹是合作能力信号。它们都是一般模型的实例，而不是模型的目的。

# 5. 信息价值：什么时候询问，什么时候直接行动

行动可以分为**利用型**（推进目标）和**信息型**（减少会影响后续决策的不确定性），同一行动也可能同时做到两者。信息价值不是“知道更多”本身，而是**新信息是否可能改变最优行动**。

$$
\operatorname{EVSI}=\mathbb E_{o\sim p(o\mid b,a_{\mathrm{ask}})}\left[\max_{a}\mathbb E(U\mid b,o,a)\right]-\max_a\mathbb E(U\mid b,a).
$$

净信息价值为 EVSI 减去询问成本、时间延误及对互动关系的潜在影响。若新信息不会改变行动，EVSI 通常不值得支付额外成本；若某一隐藏约束会导致完全不同的行动，则主动求证可能十分有价值。

**完整策略工具箱**可以包含：直接答复、先澄清、低成本试探、交付可验证证据、等待关键反馈、选择稳健方案、拒绝无法兑现的承诺、请人确认及终止无收益的互动。不是每次都要说得更多。

# 6. POMDP：把一次博弈变成长期动态决策

只优化当下的一句回复可能牺牲长期信任、后续合作和信息积累。用信念状态 $b_t$ 构造部分可观测马尔可夫决策过程（POMDP），即在不知道真实隐藏状态时，直接对**信念空间**规划。

$$
V(b)=\max_{a\in\mathcal A}\left\{\bar r(b,a)+\gamma\sum_o p(o\mid b,a)V(\tau(b,a,o))\right\}.
$$

其中 $\tau$ 是前述贝叶斯信念更新，$\bar r$ 是当前信念下的平均即时收益。该式同时考虑：行动今天带来什么、会暴露什么新信息、会如何改变对方和环境、未来会产生哪些行动机会。

对高维、多人和长时程问题，不必精确求解完整 POMDP。实际可以采用短期滚动规划、采样式树搜索、场景模拟、上下文 bandit 或模型预测控制；**通用的是状态与策略接口，不要求所有场景使用同一种求解器。**

### 6.1 长期期望与长期胜率

应把两个目标分开报告：

- **累计期望收益**：$J(\pi)=\mathbb E[\sum_t\gamma^tr_t]$，体现时间、成本、收益和信任；
- **达到目标的概率**：$P_{\pi}(\text{success by }T)$，体现任务胜率。

它们可能不一致。决策系统可采用多目标最优化、约束规划或明确权重，而不是未经授权把“成交率”当作唯一目标。

# 7. 通用 LLM 决策架构：与语言生成模型解耦

![通用长期决策优化层：从文本理解、状态估计到规划、生成、反馈与审计](llm_long_horizon_architecture.png){width=90%}

**层 1｜理解与证据摄取。** LLM 从自然语言、工具结果、任务状态中抽取可核验事实、候选解释和新观察；每条证据附来源、时间戳、可信度与可见范围。不要把生成模型的直觉概率直接当成真实成交概率。

**层 2｜高维信念引擎。** 维护 $b_t(\theta)$：多主体、分层、动态的隐藏状态后验。允许多个竞争假设同时存在，能够回答“哪些推断最不确定”“什么证据可以区分它们”。

**层 3｜世界模型与他人策略。** 估计 $p(o_{t+1},\theta_{t+1},x_{t+1}\mid b_t,a_t)$；涵盖环境状态变化、对方潜在反应、第三方与自身行动之间的反馈。

**层 4｜决策规划器。** 生成多个合法的高层动作，预测长期奖励分布与成本，计算信息价值和风险，并按照用户授权的目标选择策略。高收益但违反硬约束的动作直接排除。

**层 5｜语言与动作执行。** LLM 将选中策略转换为具体回复、工作交付、工具调用或等待动作。这里是语言层，不负责私自修改优化目标。

**层 6｜审计与学习。** 在采取行动**之前**保存信念、候选策略、预测分布、所选策略和理由；观测到结果后记录残差，评价校准与反事实收益，持续更新模型。

## 7.1 两条可选控制路径

**路径 A：策略级控制（建议先做）。** 每一轮交互前生成几个不同的行动方案，决策器选择策略，再由同一个 LLM 表达。可重复验证，接口清晰，也不依赖底层模型是否开放 logits。

$$
\pi_{\mathrm{plan}}(a\mid b)\propto\pi_0(a\mid h)\exp\{Q(b,a)/\tau\},\qquad a\in\mathcal A_{\mathrm{valid}}.
$$

**路径 B：词元级控制（后续探索）。** 对 LLM 每个词元的分布引入价值函数：

$$
p_{\mathrm{ctrl}}(w_t\mid w_{<t},b_t)\propto p_{\mathrm{LLM}}(w_t\mid w_{<t},h_t)\exp\{\beta Q_{\mathrm{future}}(b_t,w_{\le t})\}.
$$

这里的 $Q_{\mathrm{future}}$ 必须与真实的延迟任务收益有关，而不是仅用“这句话听起来很聪明”评分。词元级方法的计算与训练成本高、信用分配困难；不应因为 LLM 本来就输出词元概率，就认为它已经在优化真实长期效用。[R4]

# 8. 可复核的数学主张与不确定性

**理论定位。** 如果隐藏状态模型、转移模型、观测模型和效用定义正确，且信念更新与规划充分精确，那么在相应 POMDP 假设下，信念空间规划能够优化模型定义的期望累计收益。这个陈述是**建模条件下的最优化原则**，不是“任何现实场景都会提升收益”的保证。

实际科研要同时估计五种不确定性：隐藏状态的不确定性、对方行为的随机性、模型参数的不确定性、外部变化、以及行动效果不可识别的部分。允许模型回答“目前无法判断”；估计不确定性越高，越倾向信息获取、稳健行动或人工确认。

## 8.1 为什么需要专门验证高维信念是否准确

高维框架的价值是容纳复杂性；预测能力必须来自验证。对于可观测到真实标签的变量，使用 Brier score、对数损失、可靠性图、区间覆盖、分层误差和时序预测。对于无法直接观察的隐藏变量，评估它对**未来可观察行为和结果的预测能力**，并比较是否胜过更简单的模型。

隐性条件可以彼此混淆：例如“迟迟不回复”可能对应忙碌、经费不足或不感兴趣。多个解释可能具有相同可观察预测；这时应显式保留不可辨识性，而非输出一个高置信度人设。因果结论必须依靠有效干预或实验设计，不从相关性直接推出心理机制。

# 9. 假想示例：为何“需求分析 × 信号”会影响行动

此例只用于演示公式，**不是对真实张强教授或任何人的概率评估**。

假设对方有三种隐藏状态：$\theta_1$ 强调快速交付、$\theta_2$ 强调深度严谨、$\theta_3$ 暂无资源。演示先验为 $b=(0.45,0.35,0.20)$。两个策略为 A“先完成可复现成果，再简要汇报”和 B“先进行较长的需求确认”。假设在三个状态下，A 的标准化收益分别为 $(0.85,0.72,0.05)$，B 为 $(0.45,0.65,0.10)$。

$$
\mathbb E[U\mid A]=0.45(0.85)+0.35(0.72)+0.20(0.05)=0.6445.
$$

$$
\mathbb E[U\mid B]=0.45(0.45)+0.35(0.65)+0.20(0.10)=0.4500.
$$

所以在**这些人为设定的概率和收益**下，A 是更好的行动。若随后得到可靠信息证明预算极可能缺失，或需求确认能消除关键技术歧义，模型的最优行动可以改变。这解释了为什么应当做**动态决策**而非机械遵守“总是越快越好”。

# 10. 科研方法：如何证明长期决策层真的有效

研究必须将“预测对方”与“改变结果”分开评价。即使隐藏状态预测更准，实际决策收益也未必提高；即使某种策略的胜率提高，也需要排除任务难度和对照组不公平。

## 10.1 通用实验设计

研究单元为一次**完整的交互轨迹**，不是单句回答。至少在四类任务中验证：科研协作与任务分配、招聘与合作、客户服务或谈判、通用工具型个人助理。奖励函数和合法动作由场景适配器给出；高层信念、规划和审计机制共用。

| 实验组 | 设计目的 |
|:---|:---|
| B0：原始 LLM | 直接根据历史生成行动或回复 |
| B1：LLM + 长上下文推理 | 控制额外推理文本带来的收益 |
| B2：LLM + 固定需求标签 | 测量粗粒度用户画像的效果 |
| B3：LLM + 显式后验，但贪婪决策 | 单独测量状态建模价值 |
| B4：LLM + 后验 + 长期规划 | 单独测量多轮规划增量 |
| B5：完整系统，加入信息价值和对手信念 | 测量主动探索及信号机制增量 |
| B6：预知隐藏真值的规划器（仅模拟） | 给出有条件的上限，而非可部署方法 |

**公平控制：**相同基础 LLM、相同观察权限、相同可用动作、相同任务分配及资源预算；冻结测试任务；所有方法按相同的后续结果评价。先以可控模拟环境检查模型识别能力，再在有真实反馈的环境中评估外部有效性。不得把模拟角色的表面一致性当成真实人类准确率。

## 10.2 指标、验收门槛与因果识别

- **预测质量：**隐藏状态可观测分量的 Brier/log-loss、校准误差、未来行为预测与跨域泛化；
- **决策质量：**每轨迹折现收益、目标成功率、最差分位收益、时延成本、撤销/违约事件；
- **信息效率：**每次主动询问的净信息价值、改变最优动作的比例、额外观察成本；
- **信号价值：**行动是否改变对方可观测判断或行为，以及这种变化与收益的关系；
- **稳定性：**不同随机种子、不同基础 LLM、任务难度、隐藏状态分布及时间跨度；
- **审计性：**预测事前锁定率、证据引用正确率、价值预测—实测残差、反事实说明覆盖率。

真实部署使用适当的随机对照或分阶段试验，并计入延迟兑现的收益。若从历史日志估算新策略价值，可研究逆概率加权或双重稳健估计，但必须满足动作覆盖等条件，不能只让另一个 LLM 主观打分。[R7]

### 10.3 科研验收门槛

- **G0：**场景、状态、合法行动、奖励、硬约束和信息权限定义完整。
- **G1：**高维信念在冻结测试集上比强基线更准确或更校准；否则说明哪些变量不可识别。
- **G2：**独立的长期规划优于贪婪策略，收益以完整轨迹统计。
- **G3：**主动获取信息带来的收益超过其成本。
- **G4：**加入信号／二阶信念后有额外稳定收益；不成立则保留更简单模型。
- **G5：**在多个环境或多个基础 LLM 上复现，而非仅单一场景有效。
- **G6：**真实或高保真环境下验证，不把模拟胜利直接宣传为现实效果。
- **G7：**任何收益结论有事前协议、对照、置信区间或后验不确定性及审计轨迹。

# 11. 系统接口、记录和可扩展性

**通用输入：**环境描述、允许观察的历史、当前目标、用户授权、合法动作集合、场景奖励与成本。**通用输出：**信念摘要、候选动作、预测收益及风险、所选动作、解释与后续检验项。

```json
{
  "time_step": 7,
  "scenario": "generic_multi_agent_task",
  "observations": [{"source": "verifiable_event", "value": "..."}],
  "beliefs": [{"latent_variable": "resource_constraint", "posterior": "distribution", "evidence_ids": ["O3"]}],
  "candidate_actions": [
    {"action": "deliver_evidence", "expected_return": null, "uncertainty": null},
    {"action": "ask_clarifying_question", "expected_return": null, "uncertainty": null}
  ],
  "selected_action": "...",
  "forecast_frozen_before_action": true,
  "next_observation": null,
  "realized_outcome": null,
  "audit_status": "PENDING"
}
```

这个结构应能记录**概率分布或其近似表达**，不能将模型随口生成的单个数字当成已校准后验。每一个情境只需提供对应的观察、动作和收益适配器；公共决策层不改定义。重要的设计对象是长期策略，而非某一套固定提示词。

# 12. 与现有研究的关系：哪些已有，哪些值得研究

截至 2026 年 11 月，以下工作已经覆盖构想的若干组件。因此本研究的潜在贡献**不是首先提出贝叶斯模型、POMDP、LLM 控制或对手建模**，而可能在于它们的**统一、通用、高维、长时程和可检验组合**。

| 方向与文献 | 已有能力 | 与本构想的关系 |
|:---|:---|:---|
| 贝叶斯心智理论 [R1] | 从行为反推他人的信念、欲望和主观信息 | 高维隐藏状态与逆向决策的理论来源 |
| 生成式 Agent [R2] | 记忆、反思和规划产生连贯行为 | 可扩展为显式概率与收益审计 |
| 2026 对手偏好估计 [R3] | LLM 抽取定性线索，贝叶斯追踪偏好 | 与“需求推断＋概率更新”直接相关，但主要面向谈判 |
| 词元级受控解码 [R4] | 使用前缀价值评估控制基础模型输出 | 说明低层生成可以外接价值控制，但奖励是否长期有效需另证 |
| 长时程信念模块 [R5] | 将状态不确定性与策略选择解耦 | 直接相邻的外置决策架构研究 |
| 独立信念引擎 [R6] | 在部分可观测任务中单独追踪后验 | 与“LLM 外置高维信念层”相邻；属于预印本证据 |
| 序贯策略离线评价 [R7] | 从部分反馈评价历史决策策略 | 为真实长期收益比较提供方法 |
| 2026 产业谈判优化 [R8] | 通过异质奖励优化多轮业务对话 | 有实际部署证据，但不是跨场景通用框架 |

**待识别的研究缺口（假设，不是已证实的新颖性）：**能否把高维多主体隐变量后验、战略信号、主动信息获取、通用动作接口及长期效用评价结合为跨领域层，并证明其收益来自**正确的信念—决策链**，而不只是生成更多文字、消耗更多推理预算或模拟环境偏好。

# 13. 实施路线与冻结原则

**阶段 A｜理论与基准。** 固定通用状态和观测接口、场景协议、目标函数及最小基线；定义可辨识性、概率校准和长期收益。先验证数学问题自洽，再开发复杂代理。

**阶段 B｜两个极简可控环境。** 一个纯信息价值环境，一个含战略信号和隐藏竞争者的双主体环境。隐藏真值由实验者掌握，能检验信念恢复与策略最优性。

**阶段 C｜跨场景研究。** 至少三类环境、多个基础 LLM、统一预算和预注册消融，比较 B0—B6。单场景结果和跨场景结果分别汇报。

**阶段 D｜真实反馈与产品形态。** 在合法、透明且获得适当授权的业务或协作环境中评估长期实际收益；先做建议模式，再逐步考虑自动执行。保存反事实检查、日志和人工确认。

**冻结规则。** 研究结论须明确区分：（1）数学上可表达；（2）系统可运行；（3）隐藏状态预测更准确；（4）长期收益确实提升；（5）收益跨域稳定。任何一个阶段失败都应保留证据，并用于重新定位机制。

# 14. 使用边界与长期价值

这个系统应优化用户授权且透明的长期目标，包含守信、可撤回、隐私、风险和非伤害约束。对方的隐藏需求是**概率变量，不是可被宣称已获知的私人事实**；不得通过未授权的个人数据推断敏感特征，也不以欺骗、施压或隐瞒重要信息换取高分。

最终愿景是一个**可替换语言模型的通用长期决策层**：任何能够提供观察和可执行行动的场景，都可以调用同一套信念更新、收益规划和决策审计机制。研究成功与否，由独立实验中的长期回报、校准质量和稳健性决定。
