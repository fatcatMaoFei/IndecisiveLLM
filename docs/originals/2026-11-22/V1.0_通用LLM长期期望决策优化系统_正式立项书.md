# 通用 LLM 长期期望决策优化系统

**General Long-Horizon Decision Optimization for LLM Agents**

**正式科研立项书与架构规范｜V1.0**

2026 年 11 月 22 日  ·  项目状态：**正式立项 / 理论与实验体系设计**

**一句话定义：**在语言模型与外部世界之间引入一套可复用的**高维概率决策层**，把隐藏状态推断、多主体相互信念、信号博弈、信息价值、长期规划和决策审计统一起来，让 LLM 能够在跨场景的长期交互中选择预期收益更高、过程可检查的行动。

> **立项主张：**我们不是开发一个销售话术优化器，也不是让 LLM 单纯生成更漂亮的答案；我们要建立一套通用的智能体决策操作系统。语言生成由 LLM 执行，概率信念、策略比较、长期收益预测、证据记录和事后校准由独立的决策层负责。模型必须能够说清：它观察到了什么、相信什么、为什么选择该行动、预计发生什么、最后是否兑现。

**科学目标：**证明引入显式概率决策层，能够在公平计算和行动预算下，使基于 LLM 的智能体在多种部分可观测任务中取得可重复的**长期实际效用增量**，并识别哪些机制产生增量。

**产品目标：**形成可以接入不同 LLM、不同业务和不同工具的通用决策中间层，提供行动建议、决策可视化、自动化规划与结果审计；以增量收益、节省成本、可解释性和稳定性作为产品价值指标。

**学术定位：**以顶级人工智能会议的完整研究标准设计方法、理论、跨场景实验及消融；论文贡献与投稿决定由实验结果验证。

# 0. 正式立项章程

## 0.1 核心问题与 So what

普通 LLM 的词元概率描述的是给定上下文时某个输出的生成倾向；它不自动等于“某行动成功的概率”，更不自动等于长期收益。现实决策还涉及未公开需求、资源约束、竞争者、时间、风险、他人对我们的信念，以及每次行动造成的状态变化。

本项目要解决的不是表达流畅性，而是一个可检验的决策缺口：**当行动结果延迟兑现、真实状态不可直接观察、多个主体会彼此更新判断时，如何把语言模型变成能够系统规划、预测、执行和审计长期策略的智能体？**

适用任务包括但不限于科研协作、项目谈判、招聘合作、客户服务、个人助理、资源分配、多智能体协调。所有场景使用共享的概率信念—策略—反馈接口；场景差别通过观察、合法动作、效用和约束适配器表达。

## 0.3 必须统一实现的八个核心模块

| 模块 | 进入系统的内容 | 应产出的可核验证据 |
|:---|:---|:---|
| ① 高维隐藏状态 | 需求、资源、偏好、限制、竞争者、环境、历史行为、风险、时间及其依赖 | 联合后验、变量关联与置信/不可识别区域 |
| ② 多层信念 | 对方怎样想、怎样看我们，以及行动如何改变其判断 | 一阶和有限二阶信念、可检验行为预测 |
| ③ 动态概率更新 | 新回复、任务变化、工具结果、现实事件 | 前后后验、似然依据、状态转移与校准轨迹 |
| ④ 信息价值 | 直接行动、询问、试探、等待的机会成本 | 不同信息动作的净价值与策略变化 |
| ⑤ 信号博弈 | 我们交付、承诺、回应的可信信号及其他主体反应 | 他人可观察行动变化、后验更新预测 |
| ⑥ 长期期望优化 | 多轮结果、延迟回报、成本与风险 | 候选动作的长期价值分布、选择与后悔 |
| ⑦ LLM 执行与表达 | 任务理解、提议、文本输出、工具调用 | 策略到实际回复/行动的对应与执行结果 |
| ⑧ 决策审计与持续学习 | 事前冻结预测，事后获取实际结果 | 可追溯决策链、预测残差、收益估计、模型修正 |

**整合原则：**八个模块是共同运作的动态系统，不是八个互不相连的功能。一个行动可以同时产生收益、获取信息、改变对方信念和竞争状态，从而改变后续最优策略。

## 0.4 研究成功的判定

先证明系统**能运行**，再证明**后验可校准**，再证明**决策收益有增量**，最后证明**增量可跨场景复现**。可解释性与商业价值必须分别用可检查日志及真实决策结果测量。功能完成不是收益证明；负结果用于定位需要改进的机制。

# 1. 研究问题与原始动机

**研究问题。** 在信息不完全、多主体交互且目标延迟兑现的环境中，能否在现有语言模型之上增加一层**显式、可校准、可规划的长期决策机制**，使其长期累积收益高于只根据对话历史直接生成下一条回复的 LLM？

最初的直觉来自人际合作与 RA 招聘：对方可能重视执行速度、科研质量、未来合作成本、经费、其他候选人等不同因素。行动者不知道这些因素的真实数值，但可以从对方主动邀约、提出任务、回复方式等信号形成概率判断。行动不只是“回答”，还可能是快速交付、补充证据、询问关键信息、保持等待或改变沟通时机。高质量交付本身也是一种**可核验的能力信号**，可能改变对方的判断。

这是一种通用结构，而不只是招聘心理学：**需求推断 → 隐藏状态建模 → 信号观测 → 策略选择 → 环境和他人信念变化 → 收益反馈 → 模型更新。**

## 1.1 核心研究假设（待验证）

- **H1｜信念价值：**显式、校准的隐藏状态后验优于直接让 LLM 在长上下文中隐式猜测。
- **H2｜规划价值：**在同一 LLM、同一工具、同一交互预算下，长期决策规划优于只看下一步得分的策略。
- **H3｜信息价值：**允许主动询问或观察的策略，在信息成本可控时优于始终立即行动。
- **H4｜信号与多主体价值：**建模“对方如何看待我们的行动”能在某些战略交互中提高决策质量。
- **H5｜跨场景迁移：**共享的信念—决策接口在多个环境中均能产生可测增量，而不是依赖某一个销售或谈判基准。
- **H6｜可审计性：**记录每一步信念、预测、候选行动及实际结果，可以区分“改变话术”和“改善长期收益”。

# 2. 通用数学定义

将每个问题环境表示为多主体、部分可观测的序贯决策过程。时间步 $t=0,1,\ldots,T$，各场景有不同的观测、动作和奖励定义，但共用一个决策接口。

| 符号 | 含义 | 实际例子 |
|:---|:---|:---|
| $x_t$ | 环境可见状态 | 任务进度、历史对话、已发生的交付 |
| $\theta_t$ | **高维隐藏状态** | 需求、偏好、预算、竞争者、权限、隐性约束 |
| $h_t$ | 截止 $t$ 的可用历史 | 观察、回复、行动及已兑现结果 |
| $b_t(\theta)$ | 对隐藏状态的后验信念 | 某项需求或约束为真的概率分布 |
| $a_t$ | 可执行的**策略性行动** | 提问、承诺、交付、等待、选择方案或回复 |
| $o_{t+1}$ | 行动后的新观测 | 对方答复、资源状态变化、实验结果 |
| $r_t$ | 即时效用及成本 | 任务推进、信任变化、时间与资源开销 |
| $\pi$ | 从信念到策略动作的政策 | 先收集信息还是立刻交付 |
| $\gamma$ | 长期折现因子 | 对长期目标相对即时收益的重视程度 |

**一次性选择的贝叶斯决策问题：**

$$
a^*=\arg\max_{a\in\mathcal A}\;\mathbb E_{\theta\sim p(\theta\mid E)}[U(a,\theta)] .
$$

这保留了最初设想：根据观察证据 $E$ 推断未知需求和决策框架，再选择期望收益最大的交付或沟通方式。当收益或行动带有随机性时，$U$ 还应对后续响应与外部变化取期望。

**长期目标：**

$$
\pi^*=\arg\max_{\pi}\;\mathbb E_{\pi}\!\left[\sum_{t=0}^{T}\gamma^t\,r(x_t,\theta_t,a_t,o_{t+1})\right]
$$

可同时加入执行成本、关系质量、信誉、可信度、风险、合规性及其他场景目标。更通用的做法是令 $r_t=\mathbf w^\top\mathbf r_t-c_t$，其中权重 $\mathbf w$ 随任务和用户授权而定；对不可交易的底线使用**硬约束**，而不是用高收益将其抵消。

## 2.1 贝叶斯隐藏状态更新

收到新观察后，不是把对方固定成某个人设，而是更新完整的概率分布：

$$
b_{t+1}(\theta')\propto p(o_{t+1}\mid\theta',a_t,h_t)\int p(\theta'\mid\theta,a_t,x_t)\,b_t(\theta)\,d\theta .
$$

第一部分是观察的**似然**，第二部分是隐藏状态**随时间和行动的转移**。例如，对方今天的预算、紧迫性或信任程度可能因外部事件和我们交付的成果而变化；不能把它们全当静态参数。

信号也可能是战略性的：同一句“之后再谈”，在对方确实没经费、正在比较候选人、或礼貌婉拒时产生的概率不一样。更新时应比较多个竞争解释，不凭单个措辞直接下结论。

# 3. 高维隐藏状态：完整角色与决策框架

我们不预设只有三个性格标签。隐藏状态是**多层、多主体、可扩展的联合变量系统**。高维允许表达丰富现实；实际估计时应采用层级结构、稀疏依赖、先验与可辨识性检验，避免每个场景都需要海量样本。

| 模块 | 典型隐藏变量 | 可用观测或证据 |
|:---|:---|:---|
| 目标与需求 | 近期目标、长期目标、排序权重、不可牺牲条件 | 任务描述、已选择的方案、反复强调的标准 |
| 资源与约束 | 经费、时间、人力、制度门槛、审批权限、排期 | 官方流程、行动窗口、明确的限制陈述 |
| 选择空间 | 其他候选、替代方案、退出选择、机会成本 | 公开招聘、竞争强度、对比性问题 |
| 决策框架 | 风险偏好、损失厌恶、证据要求、否决规则 | 以往决策、对风险与失败的反应 |
| 信念与认知 | 对我们能力的判断、对外部世界的主观判断 | 追问、赞许、质疑、是否给予信任 |
| 高阶信念 | 对方认为我们如何理解他；其他主体如何评价双方 | 多轮互动和第三方可公开信号 |
| 时间与阶段 | 紧迫性、截止日、决策阶段、关系成熟度 | 回复节奏、任务安排、是否主动推进 |
| 社会与组织 | 影响者、负责人、决策链、社会规范 | 组织结构、会议参与者、信息转发 |
| 关系与信誉 | 信任、可靠性评价、过去承诺兑现情况 | 历次交付、后续合作意愿 |
| 情境与外因 | 市场变化、政策、突发事件、可选资源变化 | 可验证的外部事件和系统状态 |
| 感知与观测 | 信号噪声、选择性披露、沟通渠道、误解概率 | 邮件、口头消息、平台行为和延迟 |
| 自身状态 | 能力、时间预算、可承诺范围、目标、成本 | 自身资源、任务日志、实际交付 |
| 多主体耦合 | 竞争者行动、联盟、互相影响、共同资源 | 公开事件、合作网络、可获准的记录 |

**关键建模原则：**保留联合依赖，而不是把所有变量独立相乘。例如“紧迫性”和“预算”可能通过“审批周期”关联；“竞争者数量”和“招聘概率”不一定线性相关。可用动态概率图、分层贝叶斯模型、粒子信念或结构化近似后验来处理。

隐藏状态需分为：已确认事实、可验证但未确认、统计推断、无法识别。**增加变量数量不自动产生准确性**；准确性由可检验的预测质量、校准性及跨环境稳定性决定。这不会削弱框架的高维定位，反而使高维框架成为科学模型。

# 4. 信号博弈：行动也在改变对方的信念

传统“理解对方”只是在推断；信号博弈进一步承认：**我们的行动会作为证据，被对方用来推断我们的类型和能力**。行动者与对方互相更新认知，这可以改变后续选择。

设 $q$ 为观察者对某一能力的先验概率，$s$ 为可核验交付信号，$L_H=p(s\mid H)$ 和 $L_L=p(s\mid\neg H)$ 是两种能力类型下发出信号的似然，则：

$$
p(H\mid s)=\frac{L_Hq}{L_Hq+L_L(1-q)} .
$$

当 $L_H/L_L$ 大于 1 时，信号使高能力假设的后验上升。交付速度、结果质量、复现记录、长期一致性等可以组成信号，但其区分力必须通过观察数据估计，不能单凭我们认为“震撼”就设定一个很大的似然比。

进一步引入**有限层级的心智模型**：我们持有对方偏好的信念；对方也持有关于我们的信念；在必要时加入对方如何理解我们意图的第二阶信念。递归层数应可控，并通过消融判定额外复杂度是否值得。

**跨情境意义。** 面试中快速高质量交付是能力信号；科研合作中公开实验与负结果是可靠性信号；客户服务中兑现承诺是信任信号；协作 Agent 中可检验的行动轨迹是合作能力信号。它们都是一般模型的实例，而不是模型的目的。

# 5. 信息价值：什么时候询问，什么时候直接行动

行动可以分为**利用型**（推进目标）和**信息型**（减少会影响后续决策的不确定性），同一行动也可能同时做到两者。信息价值不是“知道更多”本身，而是**新信息是否可能改变最优行动**。

$$
\operatorname{EVSI}=\mathbb E_{o\sim p(o\mid b,a_{\mathrm{ask}})}\left[\max_{a}\mathbb E(U\mid b,o,a)\right]-\max_a\mathbb E(U\mid b,a).
$$

净信息价值为 EVSI 减去询问成本、时间延误及对互动关系的潜在影响。若新信息不会改变行动，EVSI 通常不值得支付额外成本；若某一隐藏约束会导致完全不同的行动，则主动求证可能十分有价值。

**完整策略工具箱**可以包含：直接答复、先澄清、低成本试探、交付可验证证据、等待关键反馈、选择稳健方案、拒绝无法兑现的承诺、请人确认及终止无收益的互动。不是每次都要说得更多。

# 6. POMDP：把一次博弈变成长期动态决策

只优化当下的一句回复可能牺牲长期信任、后续合作和信息积累。用信念状态 $b_t$ 构造部分可观测马尔可夫决策过程（POMDP），即在不知道真实隐藏状态时，直接对**信念空间**规划。

$$
V(b)=\max_{a\in\mathcal A}\left\{\bar r(b,a)+\gamma\sum_o p(o\mid b,a)V(\tau(b,a,o))\right\}.
$$

其中 $\tau$ 是前述贝叶斯信念更新，$\bar r$ 是当前信念下的平均即时收益。该式同时考虑：行动今天带来什么、会暴露什么新信息、会如何改变对方和环境、未来会产生哪些行动机会。

对高维、多人和长时程问题，不必精确求解完整 POMDP。实际可以采用短期滚动规划、采样式树搜索、场景模拟、上下文 bandit 或模型预测控制；**通用的是状态与策略接口，不要求所有场景使用同一种求解器。**

### 6.1 长期期望与长期胜率

应把两个目标分开报告：

- **累计期望收益**：$J(\pi)=\mathbb E[\sum_t\gamma^tr_t]$，体现时间、成本、收益和信任；
- **达到目标的概率**：$P_{\pi}(\text{success by }T)$，体现任务胜率。

它们可能不一致。决策系统可采用多目标最优化、约束规划或明确权重，而不是未经授权把“成交率”当作唯一目标。

# 7. 通用 LLM 决策架构：与语言生成模型解耦

![通用长期决策优化层：从文本理解、状态估计到规划、生成、反馈与审计](architecture.png){width=90%}

**层 1｜理解与证据摄取。** LLM 从自然语言、工具结果、任务状态中抽取可核验事实、候选解释和新观察；每条证据附来源、时间戳、可信度与可见范围。不要把生成模型的直觉概率直接当成真实成交概率。

**层 2｜高维信念引擎。** 维护 $b_t(\theta)$：多主体、分层、动态的隐藏状态后验。允许多个竞争假设同时存在，能够回答“哪些推断最不确定”“什么证据可以区分它们”。

**层 3｜世界模型与他人策略。** 估计 $p(o_{t+1},\theta_{t+1},x_{t+1}\mid b_t,a_t)$；涵盖环境状态变化、对方潜在反应、第三方与自身行动之间的反馈。

**层 4｜决策规划器。** 生成多个合法的高层动作，预测长期奖励分布与成本，计算信息价值和风险，并按照用户授权的目标选择策略。高收益但违反硬约束的动作直接排除。

**层 5｜语言与动作执行。** LLM 将选中策略转换为具体回复、工作交付、工具调用或等待动作。这里是语言层，不负责私自修改优化目标。

**层 6｜审计与学习。** 在采取行动**之前**保存信念、候选策略、预测分布、所选策略和理由；观测到结果后记录残差，评价校准与反事实收益，持续更新模型。

## 7.1 两条可选控制路径

**路径 A：策略级控制（建议先做）。** 每一轮交互前生成几个不同的行动方案，决策器选择策略，再由同一个 LLM 表达。可重复验证，接口清晰，也不依赖底层模型是否开放 logits。

$$
\pi_{\mathrm{plan}}(a\mid b)\propto\pi_0(a\mid h)\exp\{Q(b,a)/\tau\},\qquad a\in\mathcal A_{\mathrm{valid}}.
$$

**路径 B：词元级控制（后续探索）。** 对 LLM 每个词元的分布引入价值函数：

$$
p_{\mathrm{ctrl}}(w_t\mid w_{<t},b_t)\propto p_{\mathrm{LLM}}(w_t\mid w_{<t},h_t)\exp\{\beta Q_{\mathrm{future}}(b_t,w_{\le t})\}.
$$

这里的 $Q_{\mathrm{future}}$ 必须与真实的延迟任务收益有关，而不是仅用“这句话听起来很聪明”评分。词元级方法的计算与训练成本高、信用分配困难；不应因为 LLM 本来就输出词元概率，就认为它已经在优化真实长期效用。[R4]

# 8. 可复核的数学主张与不确定性

**理论定位。** 如果隐藏状态模型、转移模型、观测模型和效用定义正确，且信念更新与规划充分精确，那么在相应 POMDP 假设下，信念空间规划能够优化模型定义的期望累计收益。这个陈述是**建模条件下的最优化原则**，不是“任何现实场景都会提升收益”的保证。

实际科研要同时估计五种不确定性：隐藏状态的不确定性、对方行为的随机性、模型参数的不确定性、外部变化、以及行动效果不可识别的部分。允许模型回答“目前无法判断”；估计不确定性越高，越倾向信息获取、稳健行动或人工确认。

## 8.1 为什么需要专门验证高维信念是否准确

高维框架的价值是容纳复杂性；预测能力必须来自验证。对于可观测到真实标签的变量，使用 Brier score、对数损失、可靠性图、区间覆盖、分层误差和时序预测。对于无法直接观察的隐藏变量，评估它对**未来可观察行为和结果的预测能力**，并比较是否胜过更简单的模型。

隐性条件可以彼此混淆：例如“迟迟不回复”可能对应忙碌、经费不足或不感兴趣。多个解释可能具有相同可观察预测；这时应显式保留不可辨识性，而非输出一个高置信度人设。因果结论必须依靠有效干预或实验设计，不从相关性直接推出心理机制。

# 9. 假想示例：为何“需求分析 × 信号”会影响行动

此例只用于演示公式，**不是对真实张强教授或任何人的概率评估**。

假设对方有三种隐藏状态：$\theta_1$ 强调快速交付、$\theta_2$ 强调深度严谨、$\theta_3$ 暂无资源。演示先验为 $b=(0.45,0.35,0.20)$。两个策略为 A“先完成可复现成果，再简要汇报”和 B“先进行较长的需求确认”。假设在三个状态下，A 的标准化收益分别为 $(0.85,0.72,0.05)$，B 为 $(0.45,0.65,0.10)$。

$$
\mathbb E[U\mid A]=0.45(0.85)+0.35(0.72)+0.20(0.05)=0.6445.
$$

$$
\mathbb E[U\mid B]=0.45(0.45)+0.35(0.65)+0.20(0.10)=0.4500.
$$

所以在**这些人为设定的概率和收益**下，A 是更好的行动。若随后得到可靠信息证明预算极可能缺失，或需求确认能消除关键技术歧义，模型的最优行动可以改变。这解释了为什么应当做**动态决策**而非机械遵守“总是越快越好”。

# 10. 科研方法：如何证明长期决策层真的有效

研究必须将“预测对方”与“改变结果”分开评价。即使隐藏状态预测更准，实际决策收益也未必提高；即使某种策略的胜率提高，也需要排除任务难度和对照组不公平。

## 10.1 通用实验设计

研究单元为一次**完整的交互轨迹**，不是单句回答。至少在四类任务中验证：科研协作与任务分配、招聘与合作、客户服务或谈判、通用工具型个人助理。奖励函数和合法动作由场景适配器给出；高层信念、规划和审计机制共用。

| 实验组 | 设计目的 |
|:---|:---|
| B0：原始 LLM | 直接根据历史生成行动或回复 |
| B1：LLM + 长上下文推理 | 控制额外推理文本带来的收益 |
| B2：LLM + 固定需求标签 | 测量粗粒度用户画像的效果 |
| B3：LLM + 显式后验，但贪婪决策 | 单独测量状态建模价值 |
| B4：LLM + 后验 + 长期规划 | 单独测量多轮规划增量 |
| B5：完整系统，加入信息价值和对手信念 | 测量主动探索及信号机制增量 |
| B6：预知隐藏真值的规划器（仅模拟） | 给出有条件的上限，而非可部署方法 |

**公平控制：**相同基础 LLM、相同观察权限、相同可用动作、相同任务分配及资源预算；冻结测试任务；所有方法按相同的后续结果评价。先以可控模拟环境检查模型识别能力，再在有真实反馈的环境中评估外部有效性。不得把模拟角色的表面一致性当成真实人类准确率。

## 10.2 指标、验收门槛与因果识别

- **预测质量：**隐藏状态可观测分量的 Brier/log-loss、校准误差、未来行为预测与跨域泛化；
- **决策质量：**每轨迹折现收益、目标成功率、最差分位收益、时延成本、撤销/违约事件；
- **信息效率：**每次主动询问的净信息价值、改变最优动作的比例、额外观察成本；
- **信号价值：**行动是否改变对方可观测判断或行为，以及这种变化与收益的关系；
- **稳定性：**不同随机种子、不同基础 LLM、任务难度、隐藏状态分布及时间跨度；
- **审计性：**预测事前锁定率、证据引用正确率、价值预测—实测残差、反事实说明覆盖率。

真实部署使用适当的随机对照或分阶段试验，并计入延迟兑现的收益。若从历史日志估算新策略价值，可研究逆概率加权或双重稳健估计，但必须满足动作覆盖等条件，不能只让另一个 LLM 主观打分。[R7]

### 10.3 科研验收门槛

- **G0：**场景、状态、合法行动、奖励、硬约束和信息权限定义完整。
- **G1：**高维信念在冻结测试集上比强基线更准确或更校准；否则说明哪些变量不可识别。
- **G2：**独立的长期规划优于贪婪策略，收益以完整轨迹统计。
- **G3：**主动获取信息带来的收益超过其成本。
- **G4：**加入信号／二阶信念后有额外稳定收益；不成立则保留更简单模型。
- **G5：**在多个环境或多个基础 LLM 上复现，而非仅单一场景有效。
- **G6：**真实或高保真环境下验证，不把模拟胜利直接宣传为现实效果。
- **G7：**任何收益结论有事前协议、对照、置信区间或后验不确定性及审计轨迹。

# 11. 系统接口、记录和可扩展性

**通用输入：**环境描述、允许观察的历史、当前目标、用户授权、合法动作集合、场景奖励与成本。**通用输出：**信念摘要、候选动作、预测收益及风险、所选动作、解释与后续检验项。

```json
{
  "time_step": 7,
  "scenario": "generic_multi_agent_task",
  "observations": [{"source": "verifiable_event", "value": "..."}],
  "beliefs": [{"latent_variable": "resource_constraint", "posterior": "distribution", "evidence_ids": ["O3"]}],
  "candidate_actions": [
    {"action": "deliver_evidence", "expected_return": null, "uncertainty": null},
    {"action": "ask_clarifying_question", "expected_return": null, "uncertainty": null}
  ],
  "selected_action": "...",
  "forecast_frozen_before_action": true,
  "next_observation": null,
  "realized_outcome": null,
  "audit_status": "PENDING"
}
```

这个结构应能记录**概率分布或其近似表达**，不能将模型随口生成的单个数字当成已校准后验。每一个情境只需提供对应的观察、动作和收益适配器；公共决策层不改定义。重要的设计对象是长期策略，而非某一套固定提示词。


# 12. 研究路线与冻结原则

**阶段 A｜理论与基准。** 固定通用状态和观测接口、场景协议、目标函数及最小基线；定义可辨识性、概率校准和长期收益。先验证数学问题自洽，再开发复杂代理。

**阶段 B｜两个极简可控环境。** 一个纯信息价值环境，一个含战略信号和隐藏竞争者的双主体环境。隐藏真值由实验者掌握，能检验信念恢复与策略最优性。

**阶段 C｜跨场景研究。** 至少三类环境、多个基础 LLM、统一预算和预注册消融，比较 B0—B6。单场景结果和跨场景结果分别汇报。

**阶段 D｜真实反馈与产品形态。** 在合法、透明且获得适当授权的业务或协作环境中评估长期实际收益；先做建议模式，再逐步考虑自动执行。保存反事实检查、日志和人工确认。

**冻结规则。** 研究结论须明确区分：（1）数学上可表达；（2）系统可运行；（3）隐藏状态预测更准确；（4）长期收益确实提升；（5）收益跨域稳定。任何一个阶段失败都应保留证据，并用于重新定位机制。

# 13. 目标边界与长期价值

这个系统应优化用户授权且透明的长期目标，包含守信、可撤回、隐私、风险和非伤害约束。对方的隐藏需求是**概率变量，不是可被宣称已获知的私人事实**；不得通过未授权的个人数据推断敏感特征，也不以欺骗、施压或隐瞒重要信息换取高分。

最终愿景是一个**可替换语言模型的通用长期决策层**：任何能够提供观察和可执行行动的场景，都可以调用同一套信念更新、收益规划和决策审计机制。研究成功与否，由独立实验中的长期回报、校准质量和稳健性决定。


# 14. 决策可视化：把黑盒行动改造成可检查的策略过程

我们追求的可解释性是**决策层可解释性**。每一步必须把可用证据、关键隐藏状态、候选策略、未来结果预测、选择理由和实际反馈对应起来。可视化面板既用于人类监管，也用于研究变量消融与误差分析。

## 14.1 六个必须可实现的界面

| 面板 | 关键展示 | 需要回答的问题 |
|:---|:---|:---|
| 证据与来源 | 信息来源、时间戳、可信度、冲突证据与权限 | 这次判断基于什么？哪些是事实？ |
| 高维信念 | 隐藏变量后验、区间、关联图、跨轮变化 | 系统当前相信什么？哪里不确定？ |
| 相互信念与信号 | 对方如何看待我们、行动后预期信念变化 | 行动为何会改变未来互动？ |
| 策略对照 | 不同行动的即时与长程收益分布、成本、风险 | 为什么不是另外一种行动？ |
| 信息价值 | 最有价值的问题/额外观察、净 VOI、可能改变的选择 | 现在该问、该做还是该等？ |
| 结果与审计 | 事前预测和事后结果、校准曲线、真实收益/后悔 | 这套策略实际上更好吗？ |

**交互原则：**用户可以点开任意策略，看到该策略依赖的变量和证据、预测收益的分解、最主要的失败情景；也可以切换某个隐藏状态的假设，观察最优行动是否改变。不可辨识的变量显示为“未知/后验宽”，不强制输出单一心理结论。

## 14.2 一条决策的可视化审计链

**观测快照**（对话与公开事件） → **隐藏状态后验**（竞争假设及其概率） → **备选行动**（至少两个） → **策略分数**（即时、长期、信息、信号、成本与风险） → **选择理由**（哪个因素改变排序） → **真实执行**（LLM 文本/工具/等待） → **结果回传**（承诺是否兑现、对象是否回应、收益如何） → **误差与更新**（哪部分模型该修）。

每个节点都有时间戳、版本、输入散列和证据链接；展示的是本轮决策当时真正可见的信息，避免事后用结果美化此前判断。

## 14.3 三个层次的可解释性

1. **过程可解释**：证据、状态、候选行动、所选策略的记录清晰。
2. **预测可解释**：哪些变量改变了不同结果的预测分布；模型预期与实际结果如何偏离。
3. **决策价值可解释**：在公平对照中，哪一部分机制真的使长期收益提高。

第三级需要实验，不能仅靠自然语言推理或可视化界面代替。我们的科学目标是逐步让三者同时成立。

# 15. 可执行系统规范与标准接口

## 15.1 分层架构与职责

建议将完整系统拆分成可替换组件。一个具体任务可用一个基础 LLM、一个世界模型和一组环境适配器运行；换模型或换场景不改变决策层的抽象接口。

| 层 | 输入 | 核心处理 | 输出 |
|:---|:---|:---|:---|
| `EvidenceParser` | 对话、工具、任务事件 | 提取事实、候选解释、来源校验 | `Observation[]` |
| `StateSchema` | 场景说明与历史 | 声明高维变量、依赖、权限与分辨率 | `LatentSchema` |
| `BeliefEngine` | 上轮后验、观察、行动 | 贝叶斯滤波、近似推断、置信度与关联 | `BeliefSnapshot` |
| `OpponentModel` | 信念、历史、行动 | 多主体行为预测、有限高阶信念 | `ResponseDistribution` |
| `WorldModel` | 当前信念、候选行动 | 状态转移、奖励与未来观测预测 | `TransitionForecast` |
| `VOIPlanner` | 信息动作、信念 | 估计询问收益、信息成本与时延 | `InformationValue[]` |
| `DecisionPlanner` | 合法动作、信念、预测、目标 | 搜索、风险约束、长期价值比较 | `DecisionRecord` |
| `LLMExecutor` | 选定策略、执行约束 | 语言实现、工具调用、交付或等待 | `ActionReceipt` |
| `DecisionAuditor` | 冻结预测、反馈、对照策略 | 校准、实际回报、反事实评价、失败归因 | `AuditRecord` |
| `VisualConsole` | 全部版本化记录 | 高维状态/证据/策略/收益可视化 | 决策面板 |

**场景适配器最小合约：**环境只需提供四类可验证对象：`ObservationSpace`、`LegalActionSpace`、`UtilitySpec`、`Transition/FeedbackInterface`。复杂人际场景允许有限二阶信念；只涉及软件执行的任务则可以减小或关闭对手信念层。通用是接口和决策机制通用，而不是为每个场景强加同一套人类心理变量。

## 15.3 一次交互的端到端过程

```text
observe new event -> verify evidence and permissions
-> update structured joint belief and opponent beliefs
-> enumerate legal actions (act / ask / wait / tool / deliver)
-> simulate counterparty reactions and future states
-> estimate long-horizon return + information value - costs - risk
-> compare candidates; save selected action and forecasts before execution
-> let LLM realize the selected strategy as language/tool action
-> await observable outcomes; record actual utility and prediction errors
-> recalibrate belief and policy; repeat until termination
```

建议实现两种实时运行模式：**影子模式**不干预基线行动，只提供策略建议与预测记录；**主动模式**在用户授权下执行策略。将语言表达质量与策略选择质量分别评价。若用户需要解释，系统应能给出可读的决策摘要和完整计算记录，而不是让 LLM 在执行后随意编造理由。

# 16. 研究主线、理论贡献候选与算法落地

## 16.1 第一科学主问题

**在高维、部分可观测、多主体互动中，显式联合后验与长期规划能否超过依赖上下文隐式决策的 LLM，并让收益来源可归因？**

研究对象是完整决策系统。预测准确性、信号强度、信息价值、动态规划和最终收益是同一机制链上的不同环节。任何一个局部模块单独有用，都不自动证明整套系统有用；反之，完整系统的收益也应能拆分归因。

## 16.2 三个最重要的可发表机制候选

**方向 A｜决策充分的高维信念（Decision-Sufficient High-Dimensional Belief）。** 不是机械追求对所有隐藏变量同样准确，而是明确哪些误差会改变最优动作。对后验表示 $\phi(b)$，以长期价值损失而非单一分类准确率衡量表示是否充分：

$$
\Delta_{\phi}(b)=V^*(b)-V^{\pi_{\phi}}(b).
$$

研究变量依赖、后验校准和决策敏感度之间的关系，提出可检验的信念压缩或注意力分配方法。保留高维真实变量体系，通过决策价值确定当前哪些变量需要优先观测。

**方向 B｜信号与信息双重作用的规划（Dual-Effect Planning）。** 某个行动可能同时达成任务、改变对方对我们的信念，并带来额外观察。研究如何联合估计这三种作用，避免只优化即时成效或只追求信息量。

**方向 C｜可校准、可审计的长期决策层（Auditable Calibrated Planning）。** 每次行动前冻结后验与收益分布；结果返回后量化校准、后悔和机制归因，逐步建立比自然语言自我解释更可靠的外部决策证据链。

这些是研究假设和方法方向；正式算法贡献需要理论命题、强基线和跨环境实验共同支持。

## 16.3 两条研究技术路径

**首选：策略级控制。** 用同一个 LLM 生成候选行动，外部 `DecisionPlanner` 比较净期望效用、风险和长期信息效应，再由同一个 LLM 实现动作。优点是与闭源和开源模型均可连接、复现性高、因果消融清楚。

**拓展：词元级价值控制。** 对部分前缀或词元使用长期结果估计调整输出分布。只有在前缀价值估计被真实长期收益训练和校准后，才检验其相对策略级控制是否带来额外效果。它是可选算法分支，不是整个架构成立的前提。

# 17. 商业应用、价值机制与产品路线

## 17.1 使用场景与可度量收益

| 环境 | 关键隐藏状态 | 典型动作 | 价值指标 |
|:---|:---|:---|:---|
| 长期客户与销售服务 | 真实需求、预算、替代供应商、权限、关系阶段 | 澄清、演示、等待、报价、提供证据 | 客户净价值、留存、履约率、成本 |
| 科研协作与项目推进 | 真实评价标准、资源约束、他人对进度和质量的信念 | 交付实验、询问要求、申请资源、改变计划 | 项目净收益、成果质量、耗时、返工 |
| 招聘与专业合作 | 岗位要求、审批、其他候选人、信任与时间 | 提交成果、面谈、跟进、收集信息 | 合作成功率、匹配度、沟通成本 |
| 多智能体协同 | 其他 Agent 的能力、目标、可信度、资源占用 | 分工、请求协助、检查结果、改道 | 联合任务成功率、冲突、延迟 |
| 长期个人助理 | 用户偏好、任务依赖、时间约束、风险容忍度 | 提醒、安排、确认、执行、等待 | 任务完成、节省时间、满意度、误操作 |
| 工业运营/资源决策 | 需求变化、延迟、库存、供应竞争、外部冲击 | 下单、排产、查询、暂停、重新调度 | 运营总成本、服务水平、尾部损失 |

**商业价值的共同形式：**同等任务规模、同等授权和成本约束下，带来更高**净长期收益**，并能解释为什么策略不同、在什么条件下有效。不同领域的奖励不需要相同，但应有明确的单位和可比较的基线。

## 17.2 小幅收益改善的规模化价值

设每期处理 $N$ 个可比较任务，增量成功概率为 $\delta$，每次新增成功带来的净价值为 $v$，系统的额外推理、人工监督和执行成本为 $C$。简单业务价值近似为：

$$
\Delta\Pi \approx N\,\delta\,v-C.
$$

**演示：**如果每期有 $100{,}000$ 个独立机会，成功率绝对增加 $0.5$ 个百分点，则理论上增加约 $500$ 个成功事件；每个事件的净价值与真实执行成本共同决定最终收益。对于长期客户与协作，若一次行动影响未来数轮，必须改用整个生命周期的折现收益，而不能把事件视为独立。

**明确的可售价值：**长期收益优化、决策依据可视化、风险可追踪、结果审计、跨模型和跨系统的标准化策略层。它既可以作为企业 Agent 的决策中间件，也可作为科研实验平台。

## 17.3 商业化采用分级路径

- **建议模式：**可解释的行动方案、概率范围和预期后果，交由人决定；验证采纳率与决策质量。
- **影子模式：**在不改变现有流程时记录替代策略，先验证概率与成本模型。
- **有限自动执行：**在明确动作范围、撤销能力和人工审批下自动执行低风险步骤。
- **持续优化：**用真实延迟反馈更新世界模型与策略；可按行业适配奖励函数与约束。

# 18. 从立项到论文与产品的统一实验计划

## 18.1 必须保留的公平对照

| 对照 | 分析目标 |
|:---|:---|
| B0 直接 LLM | 当前真实基础能力 |
| B1 LLM + 额外推理预算 | 排除仅因多花推理时间而获益 |
| B2 LLM + 高维静态画像 | 测量变量数量与画像作用 |
| B3 LLM + 动态高维后验，贪婪行动 | 单独检验预测及更新 |
| B4 B3 + 长期规划 | 单独检验时序决策 |
| B5 B4 + 信息价值 | 单独检验主动获取信息 |
| B6 B5 + 信号及二阶信念 | 检验多主体互相建模的额外价值 |
| B7 完整系统 + 审计再校准 | 检验结果反馈对长期表现的影响 |
| Oracle 仅模拟真值上限 | 衡量“信息不完全”造成的可消除损失 |

正式实验统一底层 LLM、合法动作、工具、可见历史、总计算预算和环境随机种子。评估单位是**整段交互轨迹**，不是某条回复有没有说服力。场景适配器声明收益、负收益、成本和终止条件。

## 18.2 可控环境与真实反馈的分层验证

**E0｜最小数学环境：**设计可完全枚举隐藏状态的单主体信息获取任务，计算真最优策略，用它检查贝叶斯更新、VOI 和策略规划是否数值正确。

**E1｜多主体信号环境：**存在资源限制、信任判断、竞争者、交互历史和时间成本；环境真实状态可由实验者查看，系统只能看到合法信号。验证高维后验、二阶信念、信号改变对方行为的路径。

**E2｜跨领域模拟环境：**至少三个差别明显的任务族（人际协作、工具执行、多智能体协调）；同一决策层换场景适配器，检查长期收益和稳定性。

**E3｜真实数据与受控试点：**在拥有适当授权、可记录实际反馈的环境进行影子评估和小规模对照；优先累积长期结果和真实成本。

## 18.3 统一测量指标

| 层次 | 核心指标 | 为什么需要 |
|:---|:---|:---|
| 隐藏状态 | Brier、log-loss、校准曲线、分组误差、未来行为预测 | 判定“概率准不准” |
| 决策 | 折现累计收益、成功率、后悔、最差分位损失、成本 | 判定“行动值不值” |
| 信息 | 净 VOI、信息动作成本、改变后续最优选择的频率 | 判定“先问再做值不值” |
| 信号 | 对方后续行为变化与可观测信念指标 | 判定“行动怎样改变他人” |
| 解释 | 事前冻结率、引用正确率、价值分解可复算率 | 判定“是不是决策层真使用的依据” |
| 泛化 | 新场景、新角色分布、新模型、不同时间跨度 | 判定“是否真正通用” |

对长期回报使用配对轨迹、置信区间、独立种子和冻结测试场景；延迟奖励须记录完整兑现窗口。单轮模型自评不能作为真实收益。真实交互的离线政策评价必须说明历史策略覆盖范围及估计假设。

## 18.4 研究假设及否决条件

| 假设 | 最有辨别力的检验 | 不通过时的行动 |
|:---|:---|:---|
| H1 高维后验更准确 | 比 B0/B2 的独立预测与校准 | 检查变量可识别性、模型复杂度与数据需求 |
| H2 长期规划增益 | B4 对 B3 的轨迹收益 | 检查世界模型及回报估计，不宣传规划优势 |
| H3 信息价值增益 | B5 对 B4 的净收益 | 检查询问成本、是否改变实际行动 |
| H4 信号与二阶信念增益 | B6 对 B5 的长期收益 | 分析是否需要高阶模型，简化无用部分 |
| H5 可审计持续学习增益 | B7 对 B6 的长期表现和校准 | 区分仅有日志与实际策略改进 |
| H6 跨场景通用性 | E2/E3 的迁移和共同接口 | 报告有效条件、开发场景化适配器 |
| H7 商业净收益 | 真实授权试点的 $\Delta\Pi$ | 优化资源与成本，保持建议模式 |

## 18.5 正式验收门槛

- **G0 立项完整性**：项目范围、变量体系、效用、合法动作、八模块、场景合约已确定。
- **G1 数学正确性**：可枚举环境中贝叶斯更新、VOI、状态转移及规划数值通过单元测试。
- **G2 预测可信性**：独立隐藏状态与未来行为预测有校准报告，对关键变量标注可辨识性。
- **G3 决策性能**：至少一个可控环境中，长程策略的完整轨迹收益经配对检验有增量。
- **G4 机制可归因**：信息价值、信号、多层信念的增量经过单独消融，不因额外计算预算失真。
- **G5 可解释和可审计**：事前冻结、证据关联、预测与结果对账、反事实动作可追踪。
- **G6 跨场景与跨模型**：多个不同任务族及基础模型有真实对照；新环境不重写核心决策层。
- **G7 工程交付**：开源或可交付代码、文档、容器化复现、端到端第三方测试和报告。
- **G8 真实价值**：获得授权的现实任务验证净收益及风险；如未实施则明确保留为产品假设。

验收记录采用 `PASS / MODIFY / NO-GO / NOT EVALUABLE`，必须逐项附输入、脚本、配置、结果、版本哈希和解释。数学可表达、系统可运行、预测更准、收益更高、跨域有效是五种不同的结论。

| 阶段 | 应产生的成果 | 退出门槛 |

## 19.2 最终必须提供的可交付文件

1. **项目章程与完整理论规范**（本文件）以及版本更新记录。
2. **通用决策层代码**：状态、信念、对手模型、规划、LLM执行、审计与场景接口。
3. **多场景实验包**：公开配置、固定种子、真值边界、数据、对照和原始决策日志。
4. **可视化决策控制台**：证据、隐藏状态、相互信念、策略比较、VOI、收益审计。
5. **第三方复现与验收**：从干净环境执行完整闭环，能够重算关键结果。
6. **学术研究包**：科学问题、理论、算法、主结果、消融、失败案例、有效边界。
7. **商业试点包**：场景适配器、收益指标、使用模式、资源成本、授权与风险说明。

## 19.3 正式立项结论

**决定：启动“通用 LLM 长期期望决策优化系统”独立研究主线。** 完整研究范围以本 V1.0 为准，保留 V0.1 原始构想作为历史基线。首次工程目标是实现**可校准的高维联合信念 + 长期策略选择 + 决策审计**闭环；随后用真实对照检验信息价值、信号博弈、多层信念与跨场景泛化的增量。商业化方向定位为可插拔的、可审计的 LLM 决策中间件。

**项目不可丢失的核心理念：**我们优化的是**长期真实结果**，不是单轮话术、输出长度或模型自评；我们建立的是**高维、多主体、动态、可验证的概率决策系统**，不是固定人设或单一行业的提示词工程；我们要求**实际收益证据与决策过程可视化**同时成立。
