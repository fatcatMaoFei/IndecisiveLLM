# IndecisiveLLM — E0 最小精确决策实验（2026-11-22）

状态：**数学内核验证 / 工程基线**，非 LLM 真实对照试验。原始 V0.1/V1.0 文档保持不变。

## 科学主问题

外置的、可校准的概率信念表示与长期规划，是否能在部分可观测、具有代价和战略反馈的任务中，提升真实长期效用？第一阶段先检验数学过程是否正确，不用合成环境的理论最优政策冒充超越 LLM 的证据。

## E0 环境与可测对象

隐藏状态 theta 属于 {0,1}；初始先验 P(theta=1)=p。智能体只能看到先验、可选查询、查询的噪声似然与价格；不能读取真 theta。

每个可选查询仅使用一次，得到 yes/no 回答。可立即提交二分类决策，正确奖励 +1，错误奖励 -1。查询有成本 c；后续价值按 gamma 折现。查询预算 max_queries 事前定义。

更新：b'(theta)=P(y|theta,q)b(theta)/P(y|q,b)。递推：V(b,S,h)=max{V_commit(b),max_q[-c_q+gamma sum_y P(y|b,q)V(b',S\q,h-1)]}。

对照：(1) greedy 直接提交；(2) one_step 每轮只看到本次查询后立即提交的收益；(3) exact 计算全剩余深度的贝叶斯最优规划；(4) 有隐藏真值的 oracle 在 E0 可作为概念上界，不是可部署方法。

**边界：**此原型只有二元静态隐藏状态、已知查询似然和冻结效用。多维联合后验、状态转移、对手更新、LLM 提议候选动作、风险硬约束均尚未实现。

## 第一轮验收 G1

- 极端先验、零概率观察、无信息问题、昂贵问题均正确；
- 贝叶斯后验满足迭代期望恒等式；
- 全深度规划值与独立递归策略评价一致；
- 同一任务中 exact 的精确期望值不低于 greedy 与 one_step；
- 每次动作前生成预测与决策记录，可复核。

## 已执行的 E0 结果

2026-11-22，本地 Python 3 环境，随机种子 20261122，固定 1 个手工实例和 250 个事前程序生成的合成任务。250 个任务各有 4 个查询、最多使用 3 个；随机抽样先验、信号准确性、成本和折现。**这不是一次针对 LLM 的科学胜利验证。**

- 7 项单元测试通过；
- 平均真实模型精确期望收益：greedy = 0.386628；one_step = 0.601364；exact = 0.608319；
- exact 相对 greedy 平均差额 = 0.221691；相对 one_step = 0.006955；
- exact 在 201/251 个合成任务中严格优于 greedy，在 66/251 个中严格优于 one_step；
- 对自身规划与策略评价的最大绝对误差 = 0。

上述差额取决于合成环境及已知似然，主要用于验证规划实现和研究难度设计；不做统计显著性或真实世界有效性推断。全部任务和结果由固定种子脚本重新生成，逐任务数据输出到 results/e0_seed20261122.json。

## 下一道关卡：E1 / P2

1. 从二元转为多维相关隐藏状态与状态转移，明确可识别性和可复算的联合后验。
2. 加入至少一个主动行动同时改变外部状态与未来信息的双重效应环境。
3. 用同一基础模型、相同工具及计算预算完成 B0/B1/B3/B4/B5 的轨迹评估，加入世界模型误差、校准和预算消融。
4. 从 E0 有真值的诊断走向复杂环境，不把已知动力学带来的 oracle 优势算作算法贡献。

## 近邻工作与差异化机会

- Dong et al. (ACL 2026), Value of Information: A Framework for Human–Agent Communication: https://aclanthology.org/2026.acl-long.1987/ 。单纯 VoI / clarify-or-commit 已有强近邻。
- Holt et al. (AISTATS 2026), Fact-Augmented Lookahead Planning for LLM Agents: https://proceedings.mlr.press/v300/holt26a.html 。长程搜索及状态信息已有近邻。
- Kumar et al. (2026), Towards a Belief-Based World Model for LLM Agents: https://arxiv.org/abs/2609.00455 。显式信念已有直接近邻。
- Laouar et al. (2026), Leveraging the Value of Information in POMDP Planning: https://arxiv.org/abs/2604.01434 。基于信息价值的 POMDP 规划也已有强先行。

需要优先验证的候选贡献：**决策充分的信念压缩/选择**，即减少不影响最优动作的信念推断预算、保留决策敏感的变量，并以真实价值损失和校准误差判断效果；其次是信息与信号共同改变未来状态的双重作用。仅组合既有模块不足以确认新颖性。
