# IndecisiveLLM

**通用 LLM 长期期望决策优化系统（General Long-Horizon Decision Optimization for LLM Agents）**

项目立项日期：2026-11-22。当前状态：**研究设计与验证阶段**；架构和假设已形成，尚不代表长期效用增量已被实验证实。

## 核心想法

在语言模型与外部世界之间增加**可检查的概率决策层**。LLM 处理自然语言理解、表达和行动候选；决策层管理隐状态和高阶信念、贝叶斯更新、信息价值、信号博弈、长时程规划、约束与风险、行动审计和事后校准。

基本决策闭环：

**观察 → 隐状态与他人信念推断 → 可选行动及其未来结果预测 → 长期期望效用比较 → 执行 → 反馈 → 校准更新。**

## 研究验证原则

- 核心假设是显式概率决策层能否在公平的基础模型、计算预算与行动权限下，提高**长期实际收益**，而不只是改变措辞或解释长度。
- 对比原始 LLM、更多思考/上下文、显式信念无长期规划、带长期规划、带信息价值和信号博弈的消融版本。
- 使用有真实最优解或可计算强基准的部分可观测环境开始；先测量长期回报、后悔值、概率校准、行动成本，再检验跨环境推广。
- 严格区分理论假设、已执行实验和已验证的结果。未经测试的能力不写成已证明。
